## About

This website is a personal portfolio showcasing **custom Minecraft skins**, client commissions, graphic design, **TouchDesigner** generative visual projects, and creative collaborations.

The user interface is entirely custom-built from scratch specifically for this project, without relying on third-party site templates or UI frameworks.

---

## Inspiration & originality

The visual presentation draws from established industrial and brutalist digital design conventions, utilizing heavy typography, wide negative space, a custom cursor, and scroll-triggered animations.

This project is **not** a clone, **not** a fork, and **not** a redistribution of any existing website.

The following components are completely original:
- **Source code and file architecture**
- **Page layout and styling**
- **Custom bilingual (EN/RU) localization engine**
- **Works showcase archive and presentation**
- **Interactive Connections graph**
- **Custom cursor implementation**
- **Text distortion and canvas-based effects**
- **Page transitions and scroll-driven interactions**

If you believe something infringes your rights, contact me — I will review it.
