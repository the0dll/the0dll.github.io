# the0dll — Portfolio

Портфолио Minecraft-скинмейкера **the0dll**.  
Тёмный минималистичный дизайн с плавными анимациями. Готово к хостингу на **GitHub Pages**.

## Как запустить локально

Открой `index.html` в браузере или подними простой сервер:

```bash
# Python
python -m http.server 8000

# или Node
npx serve .
```

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub (например `the0dll.github.io` или `portfolio`).
2. Загрузи все файлы из этой папки в репозиторий.
3. Перейди в **Settings → Pages**.
4. В разделе **Source** выбери ветку `main` (или `master`) и папку `/ (root)`.
5. Сохрани. Через 1–2 минуты сайт будет доступен по адресу:
   - `https://USERNAME.github.io` — если репозиторий называется `USERNAME.github.io`
   - `https://USERNAME.github.io/REPO_NAME` — для обычного репозитория

### Кастомный домен (опционально)

В настройках Pages укажи свой домен и добавь файл `CNAME` с этим доменом в корень репозитория.

## Что нужно заменить

### 1. Ссылки на соцсети

В `index.html` найди секцию `#contact` и замени:

| Платформа | Что заменить |
|-----------|--------------|
| **Discord** | `https://discord.com/users/YOUR_DISCORD_ID` → твоя ссылка (или invite-ссылка сервера) |
| **Telegram** | `https://t.me/YOUR_TELEGRAM` → `@username` или ссылка |
| **X** | `https://x.com/YOUR_X_USERNAME` → твой ник |

Также можно поменять отображаемый `@the0dll` на нужный ник.

### 2. Работы (скины)

Сейчас в блоке **works** стоят стилизованные плейсхолдеры.  
Чтобы поставить свои скины:

1. Создай папку `images/` и положи туда картинки скинов (PNG).
2. В `index.html` внутри `.work-preview` замени `.skin-placeholder` на:

```html
<img src="images/skin1.png" alt="Название скина" />
```

3. Обнови название и описание в `.work-info`.

### 3. Текст

Отредактируй:
- описание в hero
- блок **about**
- количество работ в статистике
- год в футере
